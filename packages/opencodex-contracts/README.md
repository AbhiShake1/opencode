# @opencodex/contracts

Shared runtime contracts and schemas for OpenCodex.

Includes:

- `AutomationSpec`
- `Entitlement`
- `PromptInput`
- `PermissionReply`
- `ProjectRef`, `SessionRef`, `SkillInfo`
- `TranscriptSync`

All schemas are defined with `zod` and exported with inferred TypeScript types.
